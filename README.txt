Deploy to Vercel
1. Extract this ZIP.
2. In Vercel, create a new project and choose the extracted folder or deploy it using Vercel's static-site workflow.
3. Set the framework preset to Other if prompted. No build command is needed; the site entry point is index.html.
4. Deploy, then check the live page and its links.

The contact section intentionally includes email and LinkedIn, but not the phone number shown on the previous site.
